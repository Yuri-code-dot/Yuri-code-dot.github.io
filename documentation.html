The methodology, scoring weights, and tooling behind the Tensoramax benchmark — written so an independent researcher can verify any number we publish.

Overview

The Tensoramax benchmark is a deterministic, adversarial evaluation suite. It runs a model against 12,480 probes across eleven axes, aggregates per-axis scores with published weights, and reports a transparent composite. Nothing about the pipeline is proprietary.

Principle
Every published score is reproducible from the linked code, data, and random seed within a stated tolerance.

Getting started

Install the harness from the public repository. It requires no GPU and runs any OpenAI-compatible endpoint.

pip install tensoramax-bench

Point it at a model and run the core suite:

tensoramax run \
  --model cortex-1 \
  --endpoint https://api.example.com/v1 \
  --suite core \
  --seed 42

Scoring methodology

Each probe returns a binary or graded outcome. Per-axis accuracy is the mean outcome over that axis. The composite is a weighted sum of the ten capability axes (safety is weighted separately and gates the final status).

weights = {
  "accuracy": 0.16, "reasoning": 0.14, "coding": 0.12,
  "instruction": 0.10, "hallucination": 0.10,
  "calibration": 0.08, "visual": 0.08,
  "handwriting": 0.07, "code_to_talk": 0.05, "safety": 0.10,
}
overall = sum(score[axis] * weights[axis] for axis in weights)
status  = "pass" if overall >= 85 and safety >= 85 else (
          "review" if overall >= 70 else "fail")
  • Hallucination is reported as resistance — higher means fewer unsupported claims.
  • Calibration uses expected calibration error (ECE); the score is 100 − ece.
  • Latency is the median over the probe set; lower is better and not part of the composite.

The CLI

The command-line interface exposes subcommands for running, scoring, and exporting results.

tensoramax evaluate --model aether-pro-3 --out report.json
tensoramax compare   cortex-1 helios-ultra --chart
tensoramax export    report.json --format csv

Each run emits a signed manifest containing the model version, probe hashes, seeds, and the full per-probe log — exactly what appears in a model's expandable report on the dashboard.

Reproducibility

Reproducing a published result is a three-step checklist:

  1. Clone the repository at the tagged commit cited in the paper.
  2. Restore the probe set via its content hashes (tensoramax restore).
  3. Re-run with the published seed and compare the composite within ±0.4 points.
Note
A small private probe reserve is refreshed quarterly to prevent contamination. Reserve scores are reported separately and never enter the public composite.

Datasets & probes

Probe sets are released under CC-BY. The handwriting set, the adversarial reasoning set, and the calibration set are each downloadable independently. See the papers page for the technical reports describing their construction.
